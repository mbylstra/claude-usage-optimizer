The number that matters

A percentage is half a sentence.

Overshooting the weekly cap costs you a working day. Undershooting it wastes the subscription just as surely, and much more quietly. Both mistakes come from reading usage without reading the clock beside it.

What you are told
61% used

True, and not actionable. Fast or slow? No way to tell.

What you can act on
61% used, 47% of the week gone

Ahead of an even burn — and the extension puts a number on it: 1 day 3h ahead of pace.

Pace, expressed as time

“36m ahead of pace” means you have already spent what an even burn would not reach for another 36 minutes. The same percentage gap is worth minutes on a 5-hour window and days on a weekly one — which is why raw percentage points were never the number to show.

A bar you can read at a glance

Every bar carries a vertical line at the even-burn point, so the picture and the number say the same thing. Behind it runs a scale — one tick per hour of a session, one per day of a week — so the line reads as “three hours in”.

A suggested model

Opus when both gating windows have room, Haiku the moment either is burning severely ahead, Sonnet in between. Optional notifications say which window drove the change.

Calibrated warnings

Loud only when it is worth acting on.

Thresholds are set per window, at the point where the gap actually costs you something. Being behind has one colour at any size: headroom is good news, and grading it would imply a scale you cannot act on.

The optimizer half

Unused capacity does not roll over.

Headroom you never spend is simply gone. So a launchd job runs a queued Claude Code prompt at 2 AM — but only when the week is behind an even burn. On pace, nothing runs and nothing is spent.

  • Gated on pace, not on a schedule. The job reads the same snapshot the popup shows, and runs only if the week is at least 2 hours behind.
  • A queue you edit by hand. prompts.txt at the repo root, sections split by ===. The first todo runs; its status is rewritten to completed or error.
  • Bring a repo, or don’t. A prompt with no REPO: gets a fresh git init-ed project of its own, named for the date and the first words of the prompt.
  • Watch it live, or read it later. A detached window streams the run as it happens — and opening it after the fact replays the most recent run, so you can see what the night did.

Setup

One command, then one click.

Not in the Chrome Web Store — you load it unpacked from a checkout. just setup does dependencies, the build, the native host, the queue template and the nightly job, and is safe to re-run at any point.

Install and build

brew install just node uv, then just setup from the repository root. It refuses to run if uv or claude is missing.

Load the extension

The one step it cannot do for you: chrome://extensions → Developer mode → Load unpacked → pick dist/. Pin it and sign in to claude.ai.

Queue some work

Edit prompts.txt, then press Run now in Settings to test it end to end. It ignores the pace gate and opens the live run window. 

# prerequisites (macOS)
brew install just node uv
corepack enable pnpm

# everything a fresh clone needs, in one command
just setup

# then, any time
just autonomous-dry-run        # what would run next, without running it
just trigger-autonomous-work   # run now if behind pace
just autonomous-log            # follow the run live
Scope and permissions

It reads your usage. That is all it reads.

No account to make, no key to paste, no server in the middle. The extension rides the claude.ai session you are already signed in to, and everything it writes stays inside the checkout.

Three permissions, and no more

storage, alarms, and host access to https://claude.ai/*. No content script, no cookies, no tabs.

Nothing leaves your machine

Two GETs to claude.ai’s own API, and a snapshot written to a JSON file in the repo by a stdlib-only native host. There is no third party.

Never Full Disk Access

The nightly job runs its own re-signed copy of uv, so folders you allow are allowed for that job and nothing else. Your everyday uvx stays unprivileged.
